# Spotify Clone 🎵

A responsive front-end clone of Spotify's music player interface built using HTML, CSS, and JavaScript. This project demonstrates core functionalities such as song playback, volume control, progress tracking, and a dynamic playlist.

## 🚀 Features

- 🎧 Play/Pause functionality for songs
- ⏭️ Skip to next/previous song
- 🔊 Volume control slider
- 📈 Real-time progress tracking of song playback
- 🗂️ Preloaded playlist with over 25 songs from a local directory
- 📱 Responsive design compatible with desktops and tablets

## 🛠️ Technologies Used

- **HTML5** – Structuring the layout
- **CSS3** – Styling and responsive design
- **JavaScript** – Logic for playback, volume, and progress controls
